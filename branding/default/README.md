# 公开品牌配置

使用中性产品名称 Zhuma；不包含内部品牌、内部图标、证书或更新地址。

`brand.json` 为未来发行脚本的输入，应用标识在公开发行前需要确认，不代表已经注册域名或平台身份。目前未生成产品图标，也未对上游桌面应用做改名或运行配置注入。

品牌图标：`icon.png`（1024 PNG）、`icon-source.jpg`（桌面构建输入）、`render_icon.py`（Pillow 可复现绘制）。设计为暗蓝圆角底与青蓝渐变 Z 形丝带；这是对已选定视觉概念的重新绘制，并非完全相同的原图像素。

GitHub 预览图：`social-preview.png`（1280×640）。GitHub 不支持为单个仓库设置独立的仓库头像；可在仓库 **Settings → General → Social preview** 上传该图。README 默认展示 `icon.png`。
