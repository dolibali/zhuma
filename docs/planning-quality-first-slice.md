# A-PLANQ 首批：上下文与提案约束

## 用户结果与本批边界

同一个任务在团队有很多资产时仍能发起规划，模型能看到当前目标、项目、已选真人／专家及相关资源。人工编辑过的完整工作流保留为调整基线；生成结果仍是用户可编辑、确认后才应用的提案。

本批改善输入质量与可机器检查的交接规则。它没有实现语义检索、真实能力探测、任务阶段投影或局部修改差异 UI；真实模型规划质量仍待单独评估。

## 选择与代价

- 继续使用现有 `planningPrompt → WorkbenchService.plan → parsePlanningResult`，保留持久化审计、版本检查、幂等和最多一次修复。不增加规划 Agent、运行框架或外部检索服务。
- `buildPlanningContext` 仅消费调用方已授权的快照；当前 Host 入口仍为本地 owner。B-ID0 后续提供可信 actor／空间过滤，B-AGENT 提供有时间的运行权限、连接和负载事实。在此之前，目录启用只决定候选资格，运行可用性、实时负载、执行授权为 unknown。删除跨任务的分工标题汇总，避免把已确认分配当成当前负载。
- 当前工作流或正在审阅的草案绑定资源优先；其余资源用目标／补充要求优先的本地关键词排序，项目与已选能力提供辅助匹配，中文相邻字符与英文标识均支持。相同输入按 ID 稳定排序。最多 24 个资源，其中新增相关候选最多 12 个。关键词会漏掉同义表达；用户可明确写出资源 ID／名称或先绑定，语义效果必须通过后续模型评估决定是否升级。
- 资源正文总预算为 24000 个字符、单项最多 4000；上下文序列化上限 90000。按资源数分配摘录，记录 excerpted，考虑 JSON 转义后重新收缩。可选候选先让出空间；目标、完整工作流、已选成员资料和已绑定身份不静默截断。必要基线超限或绑定超过 24 项时，模型调用前返回明确错误。字符预算不宣称是精确 token 预算。
- 资产内容是资料；不因选入候选就执行 MCP、安装插件或套用模板。停用／丢失的既有引用只报告标识，保留原图供用户核对，不发送其正文。

## 接口与失败行为

`agent-core/planning-context` 提供纯函数及预算常量，公开入口仍为 `@zhuma/agent-core`。`planningPrompt` 同时返回序列化输入和本轮候选快照；Host 用同一快照校验首次结果与修复结果，不能因为某个 ID 恰好存在于全目录就接受模型未见过的资源。

每个模型节点要求执行者、输入、文字／文件交付说明和分工理由；依赖无环且限于本工作流，成员限于任务参与范围。开启评审时要求至少一位独立评审人，允许多位真人／专家，执行者不能评审自己。小任务允许一个人工节点、无工具、不强制评审；并行节点可汇合。任务 ownerId 由用户选择，模型输出协议不允许改写负责人。阻碍问题最多三个，普通执行细节进入节点而不是问卷。

候选越界、缺少交接或无效结构复用现有 invalid-plan 修复，仍失败保留原草案；超限在模型及审计写入前失败。无持久化 schema 迁移。A 维护上下文／提案约束；B 继续维护身份、运行授权和执行事实。

## 竞品取舍

2026-10-22 查阅官方资料，未将文档当作登录后产品实测：

- [n8n AI Workflow Builder](https://docs.n8n.io/build/ways-of-building-workflows/ai-workflow-builder.md)：借鉴目标生成后审阅和自然语言调整、发送定义与连接而非凭据。这里继续保留完整编辑基线，不复制其执行运行时。
- [LangGraph workflows and agents](https://docs.langchain.com/oss/python/langgraph/workflows-agents)：借鉴编排者分配并汇总、显式依赖与结构化输出。已有 DSH 承担执行，不再引入另一套循环。
- [Dify Agent 节点](https://docs.dify.ai/en/cloud/use-dify/nodes/agent)：工具描述、授权及参数需要分别配置。这里把专家目录与真实执行能力分开，不把目录 available 当成工具连接证明。

## 退出条件与下一批

本批 CI 检查 8 个固定业务场景的候选、人员／工具变化对照、完整嵌套基线、预算及转义边界、候选范围内修复、独立评审和失败不写入。场景与捕获数据见 [首批验证](review/planq-first/README.md)。这些是契约结果，不能给真实规划打分。

真实模型另按目标覆盖、分工是否符合能力、交接是否足够、依赖／并行是否合理、是否过度拆分及局部调整是否扰动无关节点评估，并记录时延和供应商用量；本批未获授权启动付费调用，状态保留 not-run。首批之后按队列推进 TEMPLATE 的真实预览／映射／应用；局部修改差异与保护、语义质量属于后续 A-PLANQ 切片，继续保留验收缺口。
