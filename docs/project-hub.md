# 项目详情与默认上下文：首批

代码检查点 `83ab303`，基线 `8ac6cb4`。此批提供可操作的项目组织入口，FR01／03 仍为部分实现；真实身份、执行、成果查询及归档另行验收。

## 正常操作

点击项目名称进入“概览／工作／资料与成果／成员”。概览优先呈现项目背景和最近工作；工作只列本项目任务，可搜索、打开编辑再返回原项目标签。项目内可新建任务，保存新项目后直接进入详情并可立即创建工作。

编辑项目可选择默认真人／专家。新草稿继承这些参与者；创建时可以增减，换项目保留人工选择，只有点击“使用项目默认参与者”才重置。重置沿用现有负责人／模板角色校验。默认值变化不改已有任务、确认快照和职责，不授予访问权限，也不启动 Agent。

项目可关联已有 Skill／MCP／工作流定义和参考链接，保存的是同源资产 ID 与链接元数据。链接只接受无账号密码的 http(s)，不接受本地路径或可执行协议。现有规划器接收项目名称、背景、链接名称／地址和显式关联的可用资产；保留已有预算、不可用引用提示和未知运行授权。没有自动抓取链接正文或扩大任务参与者范围。

## 数据与兼容

复用 `save-project`、现有 WorkbenchService 串行／幂等存储及原五个 API，不开新数据库或 Host 路由。Project 增加可选 `defaultParticipantIds`、`assetIds`、`references`；关联 ID 必须存在、不得重复。项目 ID 与产品空间 ID 独立，没有以改名方式满足旧空间映射。

新版本读取旧项目不注入默认字段，保留旧命令指纹。旧项目未设置默认参与者时沿用原有“可参与目录”初始化行为；新建项目显式从空选择开始，AI 创建要求至少一位可参与者。停用定义仍显示停用，不表示工具已连接。

这是新版本读旧数据兼容，**不是旧版本读新字段兼容**。旧严格 schema 无法读取新增字段；Host／Client 必须成套升级，回退旧版需先备份并恢复兼容的项目定义，不能直接用旧包覆盖后假定可读。此批不自动删除新资料或提供隐式降级。

## 剩余边界

当前仅本地 owner。默认参与者不是成员授权；S1 的可信模式与有权投影仍由 B 提供，既有五入口门禁也必须覆盖项目。运行／评审中的增减人员不通过项目默认值绕过。

工作只标计划草稿或已确认，不推断执行阶段；“已接受成果”明确显示查询尚未接通。没有占位成果、假完成率或模型执行。没有归档入口，避免在缺少 B 活跃状态时使任务失去入口。项目工程连接、上传文档正文、资料权限／版本物化和真实已接受产物索引仍未交付。
