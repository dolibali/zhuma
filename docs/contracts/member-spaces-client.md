# 成员空间选择与切换边界

## 可信输入

`GET /zhuma-id/session` 的成功响应必须包含成员主体、`accountId`、`peerId` 与 `spaces: readonly { id, kind: 'personal' | 'team', name }[]`。Client 只保留这些公开字段；缺失空间数组、非法类型或重复 ID 均拒绝，空数组有效。空间类型与成员关系来自同一可信目录，不从便笺、项目 ID、旧 owner snapshot 或浏览器参数推导。

`MemberSpaceBoundary` 只管理本次已登录视图中的选择。进入时及每次实际切换重新读取 session；优先展示可信目录中的个人空间，没有个人空间时使用目录首项。空目录展示尚未分配空间，不创建模拟空间。选择的空间已不可访问时展示错误，不自动跳到另一空间。客户端不保存全局 active-space 授权事实。

## 生命周期与输入

实际切换立即移除旧空间的业务视图，待新会话／目录响应验证完成后才挂载新视图。请求代次及 AbortSignal 共同隔离快速连续选择、已卸载实例与迟到回调；成员账号变化交由登录边界失效处理。Host 的 `peerId` 是每次 HTTP 请求创建的临时 peer，不作为稳定登录会话 ID。空间失效回调绑定原视图代次，旧空间回调不能关闭新空间。

同空间普通刷新保留子视图代次和未提交输入；若刷新确认当前空间已撤销或请求失败，则关闭业务内容。主动切换且存在实际未提交产物／评审意见时，先给可取消的清空提示；取消保持原选择与内容，确认清空后切换，不迁移到新空间，返回也不恢复。退出、账号变化、权限撤销直接卸载，不等待提示。输入登记只保留表单是否有改动，既不存正文也不持久化草稿。

界面卸载／请求 Abort 不表示已经到达 Host 的开始、提交或评审操作已取消。组件不得自动补发命令、迁移产物或启动模型。

## 正式业务消费

`MemberExecutionPage` 在成员登录边界中挂载 `MemberSpaceBoundary`，按空间创建独立的 `ExecutionApi` 实例。`inbox`／`startable` 每次显式发送所选 `spaceId` 并核对响应的成员与空间回显；空结果也必须有正确回显，缺失／错误不回退全成员查询。`start-plan` 同样发送所选空间，服务在幂等重放前重新授权并核对计划归属。其响应继续使用原 disposition／reports，不添加协议没有的回显。当前页面没有 report 调用，不新增无消费者方法。

正式 HTTP 操作在发往执行服务前重新读取可信 session，确认账号与所选空间成员关系。服务对无权空间与有权空空间都可能返回空投影，回显仅关联请求，不能替代这一步或服务端授权。同一 API 实例的并发请求仅共享尚未完成的 session 读取；成功后不留正缓存，不跨成员／空间／挂载代次共享。一个等待者取消不打断其余等待者，全部取消后释放读取。预检期间切换／退出后的旧结果不使新上下文失效。

请求同时核对所绑定的成员／空间界面代次，覆盖“选择已改变或退出已开始，但 React 清理尚未发出 Abort”的窗口：旧预检完成不再派发，旧401／异常不使新上下文失效。这只是组件存活门禁，仍须执行上述可信 session 与服务授权，不构成 active-space 授权源。

预检不能确认权限或 scoped 读取失败时移除当前业务内容并保留原空间重试目标；401 返回登录，服务的命令 not-found／unavailable 等仍按实际错误处理，不伪造成功或自动重发。submit／ballot 保持原节点 DTO，不塞入服务不接受的 spaceId；其成员预检与原不可变工作项校验照常执行。选择器不替代服务授权，不按项目 ID 本地过滤，不另外保存授权或执行事实。

## 证据边界

`member-spaces.test.mjs` 验证目录／生命周期契约，`identity-api.test.mjs` 验证实际 HTTP DTO 的收窄；浏览器 `member-spaces.spec.mjs` 使用 HTTP 响应重放和边界交互夹具。夹具不是执行服务、不签发真实 cookie，不证明跨空间业务过滤。真实 Host 多成员、空业务空间、撤销、命令重授权和界面验收须使用正式集成另行验证，Node 或夹具编译通过不能替代。

`execution-scope.test.mjs` 覆盖显式 scope、回显、在途 session 共享／取消、预检拒绝、服务拒绝和迟到结果；`member-execution-spaces.spec.mjs` 通过真实 `MemberExecutionPage` 重放接口，覆盖空空间、切换／可取消清空、显式开始、预检期间切换／退出与旧开始／提交结果。协调诊断入口为 `/?member-execution-spaces&strict`，仍是响应重放，不是正式数据初始化或真实 Cookie 证明。正式应用入口继续是插件导航“我的工作”。

视觉沿用现有中性浅深 token、系统字体与公共单选控件。参考 diagram-design 的语义层级与删除冗余，将空间选择与账号操作分开，避免把所有空间摊开成卡片；不复制静态图解配色、字体或节点预算。
