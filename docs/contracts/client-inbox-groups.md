# 具体工作项分组与来源展示

对应 [#32](https://github.com/dolibali/zhuma/issues/32)。本批复用现有 InboxPanel／ExecutionWorkspace，不实现 #34 的任务集合／看板。实时分支、证据和验收结论留在 Issue／PR。

## 服务义务与计数

只呈现当前成员／空间服务已返回的 items，不从 nodes 的运行、等待或完成状态生成额外事项，也不把查看视为完成。按既有 kind／action／reason 分为交付、退回修改、评审、补充与确认；不认识的组合以及当前未接的继续处理保留在只读其他工作项，不自行消掉服务义务。

human running 的 `agent-assisted-delivery / continue-handling` 是当前服务明确提供的事项；expert running 本身不生成行动项，expert waiting-for-input 才可能给 owner 补充输入。本组件不反推、改写这些领域事实。标题和分组只标“已载入工作项”，不是任务数量、可操作数量或全空间需人处理总量，不消费尚未确认的新 counts／events 接口。

只有 submit／revise／review 三个已接动作有处理按钮，进入原有提交、修改和当前轮评审。确认、补充、重试和继续处理的未来入口只展示真实说明，不出现虚假确认或执行按钮。已接按钮也要求唯一工作项及任务／节点匹配、对应节点状态和评审当前开放轮；这只是展示可用性，不能代替服务的成员／空间／角色重授权。

节点查找同时匹配 taskId 与 nodeId；同一任务节点出现多个计划／版本时不挑最新或第一条。重复 itemId 同样不可操作。已选择后的 API、完整计划／节点身份、当前轮次、草稿与迟到回执仍沿用既有生命周期。组件收到仍可显示的上次数据时，失败刷新不自行清空义务与当前输入；初次读取失败或仍在加载时不伪装为空列表。原成员／空间失效收口始终优先，会由宿主入口移除旧内容，不能借此保留越界数据。

## 已审来源接入

`InboxPlaceWire`／`readInboxPlaces` 消费 [#85](https://github.com/dolibali/zhuma/pull/85) 冻结 `487c4626052d897df4e858145460b3451a92aa75` 已审的 `{ itemId, taskPath, ownerName }[]`，基线为其合并提交 `f20ac348909aeccd6ed5a3dd2fa77a041db2d8ca`。永久 conformance 检查直接对照实际 S1 类型，校验双向结构、键集合及可选 inbox.places 属性；不再依赖候选声明替代正式类型消费。

当前 inbox 解析可选 places，并在同一有效响应中与 items／nodes 透传到正常 InboxPanel，共用原成员／空间、API和请求代次门禁。旧响应无 places 时清除上次来源显示，保持未知；来源刷新不重置当前处理表单。没有 inbox-counts／events 客户端新方法、全空间查询或本地授权过滤。

来源只能按唯一 itemId 连接当前唯一节点。显示字段缺失、重复来源映射、重复工作项或节点版本不唯一时保持未知，不从 owner snapshot、项目 ID、notes 或 assigneeId 拼路径／姓名。缺少可定位 itemId 的位置记录属于不完整投影，按既有验证错误处理。ownerName 是任务负责人，不能冒充节点执行者；taskPath 是给定展示字符串，不拆成可导航节点，不生成不存在的工作树跳转。来源缺失本身不授予或撤销节点处理资格；工作项／节点有歧义时才关闭既有入口。多余字段不进入投影，文本按 React 普通内容转义。

独立组件预览保留用于展示测试，不把它当正常服务链路的接通证明。原4b候选类型控制保留在对应提交／PR历史，正式消费以当前S1检查和正常入口证据为准。

## 设计与证明边界

沿用 frontend-design 和 [diagram-design 固定参考](https://github.com/cathrynlavery/diagram-design/tree/7a12007b) 的语义层级、克制焦点与删减原则：分组头承载义务类别／数量，行内突出当前工作目标、给定来源和真实状态，不嵌套新卡片、不用已读隐藏义务，长路径换行。继续使用既有中性浅深 token 和公共按钮。

Node 覆盖分组、来源投影、歧义匹配、计数、失败／空状态及未接命令。浏览器重放覆盖正常 inbox 来源接通、旧无 places 兼容、来源更新／迟到隔离及独立组件预览；两者明确分开。Client 刷新不调用完成／确认／执行命令，服务仍可能补偿既有解锁，不承诺执行域零写。源码、临时类型／运输控制、SSR、响应重放、真实 Host／成员／持久化和 Native 各按实际提交和环境记录，不能相互代替。额外浏览器与同数据浅深前后／展开图由协调安排，A 不操作浏览器。
