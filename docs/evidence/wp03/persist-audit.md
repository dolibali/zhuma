# 执行台落盘失败审计

用户发起的同步命令在 `journal.save` 失败时整段退回，内存与调用前一致，不记 `persistenceFault`。只有执行器异步事件这种不能撤销的外部事实才保留内存并标出故障。已有故障不会被随后无关的成功保存清掉，只有 `rewritePersistence` 成功重写当前内存之后才清除。附件字节仍只在当前进程，不另建文件存储。删除字节和会话目录都发生在对应日志已经写上之后。
