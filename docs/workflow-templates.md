状态：A-TEMPLATE 首批已实现，待独立审查。搜索／预览／映射、缺项草稿补齐、从任务保存及团队资产编排共用原有工作台和 Host。领域与服务契约、浏览器交互、隔离官方桌面的非模型保存／冷重开分别验证，不能替代真实模型质量、执行和多人权限验收。截图及证据见[复核记录](review/templates/README.md)。

## 定义和来源

继续使用 `TeamAsset.kind=template`，正文为严格的 `zhuma-workflow-template` v1 JSON：角色槽、Skill/MCP 资源槽及既有 Workflow/WorkNode 图。模板正文上限 150000 字符；其他 Skill/MCP 仍为 8000。旧文字模板可读取和编辑，但不能直接当作结构化图应用，需显式转换保存。解析不会执行脚本、插件或连接工具。

`captureWorkflowTemplate` 保留节点工作说明、输入／交付要求、并行依赖、层级和全部评审角色；人员变成匿名角色槽，不复制任务 owner、人员 ID／姓名、个人说明或旧分工理由，资源只带名称／类型及建议目录 ID。会话、实际产物、评论和运行状态没有进入此格式。自由文字仍需在预览中核对，不承诺自动识别其全部私人内容。

实例的可选 `templateSource` 保存来源资产 ID、工作台版本和精确定义快照。这里的版本是读取来源时的 Workbench revision，尚不是资源发布版本系统；完整快照保证后续编辑模板不会回写旧实例。旧任务没有此字段，读取和幂等指纹保持兼容。

## 原子创建与缺项

`instantiate-template` 沿用同一 `command`、expectedRevision 和 requestId。Host 从当前授权目录读取真实来源，校验角色／资源映射，在一次持久化内创建草稿。新任务使用 UUID，流程／节点及缺项占位 ID 按该 UUID 派生，依赖与父节点整体重映射；不覆盖已有任务，不改来源，不发模型请求。

角色优先从本次参与者选择，资源要求类型匹配且目录启用；preferredKind 只是角色偏好。未知角色键、未参与／停用人员、错类型／停用资源、重复或自评审均拒绝。任务 owner 仍由人选择，模型或模板不代选，也不授予执行权限。

未映射的角色／资源保留在节点引用与明确的来源占位元数据中。占位不是目录成员／资产，不进入 task.participantIds，也不构造可信 actor；只在草稿验证中允许。确认前仍有引用的占位会产生具体角色／资源错误，评审开关和多人槽不会被自动删除。占位 ID 与现有真实目录冲突时拒绝创建。

`resolveTemplateBindings` 只替换仍被使用的占位，保留之后的人工配置、节点 ID 和依赖；同一个人填两个评审槽会被重复评审校验拒绝。结果仍经普通保存命令和版本检查。来源快照不能经普通 save-task 新建或改写。用户显式删除或调整节点／能力／评审属于正常编辑，不是静默丢失映射。

## 验证与接入

- 创建入口统一为“AI 规划 / 使用工作流 / 从空白开始”。选择工作流后在目录搜索、切换清单／工作流与层级预览，再绑定本次参与者与启用的同类能力；不把模板正文交给模型重新生成结构。
- 可先保存未绑定草稿，从同一任务补充真实参与者并批量映射，仍可逐节点人工修改。保存模板读取当前编辑草稿，不隐式保存或覆盖原任务；失败保留相同请求可重试。
- 团队资产中通过既有节点配置与画布编排模板，角色属于模板定义，不会写入人员目录。文字模板保留参考，由用户显式编排后转换；取消不写入。预览在弹窗真实尺寸和节点测量完成后适配全图，后续不抢占人工平移／缩放；工具栏与图分开避免遮挡。
- 领域契约覆盖来源不变、匿名化、不同实例的新 ID、嵌套／并行、多位评审、缺项草稿、确认拦截、映射范围和普通保存的来源防改。
- WorkbenchService 契约覆盖同请求／重启后的单次创建、写入失败不留下半个实例及安全重试。本批 `pnpm check` 169/169（已普通同步主线 PR #11／12），浏览器浅深两主题 50/50；后者为内存 reducer 响应重放，不是 Host 持久化或真实模型测试。
- 隔离官方 DSH 桌面走正常入口新建模板、映射创建任务、人工编辑保存、完全关闭再重开，核对实际加载 Client 字节与来源不变；规划审计记录为 0。该测试未连接真实模型／执行器，也不证明 B 的身份／空间权限。
- A 负责模板定义和 UI，B 仍负责真实 actor／空间授权、执行与交付状态。本批不创建个人／团队假权限、不消费未合入的 B DTO，也不启动执行器。

界面沿用同一选择器、节点配置及工作流画布。参考 [n8n 的模板浏览与图导入分离](https://docs.n8n.io/build/ways-of-building-workflows/use-templates.md)，展示元数据预览后再实例化；不复制其运行框架。模板预览必须显示真正的图与角色／资源缺项，不能以正文附加到模型提示词代替复用。
