# A-UX2a 目录与表单验证

修改前基线：`fd12332aa7b6cd1a141c9c1e290199bb9aa2f177`。修改后为提交本目录的 UX2a 实现，完整提交号见对应 PR。图片为官方 DSH Web Host 中的真实工作台组件，使用明确的 snapshot / 规划响应重放；数据不含业务资料，不调用模型。它们证明呈现和交互状态，不证明模型规划质量或多人执行能力。

每个场景固定 1440×900，浅色、深色分别比较；文件为 `before/after-场景-主题.png`。界面内展示六个项目、26 位成员/专家、29 项资产，包含长中文名称与多项能力。

| 场景          | 对比状态                       | 变化                                 |
| ------------- | ------------------------------ | ------------------------------------ |
| projects      | 项目目录                       | 行式布局，对齐背景、任务数和操作     |
| members       | 成员与专家目录                 | 职责与能力直接比较，增加类型筛选     |
| member-editor | 同一专家编辑                   | 名称和类型并列，缩短长表单           |
| assets        | 搜索企业采购订单资产           | 按类型、用途和状态排列，正文不占目录 |
| asset-editor  | 同一 Skill 编辑                | 正文滚动，操作始终在弹窗底部         |
| asset-picker  | 同一节点展开 Skills            | 有限高度、长名称换行、可搜索多选     |
| conflict      | 连续调整后发生冲突，再关闭提示 | 修改前恢复按钮消失；修改后仍在工具栏 |

2026-10-22 实际验证：

- `pnpm check`：131 项代码/契约测试通过；`pnpm workbench:stage` 成功构建并装入隔离测试 Host；`pnpm upstream:check` 确认固定上游未改动。
- 真实 Host：通过页面创建项目、专家和 Skill，编辑保存项目；取消编辑不修改原值。重新打开页面后逐项读取上述三个目录项，内容与保存值一致。使用官方传输和存储，没有拦截这些保存请求，没有调用模型。
- 浏览器响应重放：26 位参与者和 29 项资产的筛选恢复；编辑取消、保存失败保留草稿；保存中禁用字段且 Escape 不关闭；嵌套人员选择器取消不影响外层表单，也不应用未确认选择；Skill 搜索前后保留勾选。
- 弹窗在 1280×800、1024×768、720×450 下滚动正文，保存按钮位置不变且位于视口内，无页面水平溢出。窄视口不等于操作系统原生 200% 缩放验收。
- 规划响应重放：10 节点草案连续调整只变更第三步执行者，节点与依赖 ID 不变；冲突后关闭提示仍可恢复。取消读取确认保留预览，接受后恢复已保存工作流，全程没有写入命令或真实模型调用。

公共组件签名和数据结构不变；未验证安装版桌面、多用户认证或 B 的执行交付链路。浏览器持续 CI 在独立 A-CI1 批次补齐，本目录的图片不是自动化 CI 测试。
