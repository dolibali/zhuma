## 正式桌面与冷重开

正常侧栏在“团队工作台”下方进入“专家”，看到同一份公开演示定义。编辑质量专家，保存后清筛选并定位原 ID；切回资产目录看到同一个更新后的专家。实际存储仅一个收据、两位专家，任务内容与初始值一致，规划审计 0 条。

完全关闭后冷重开，重新选择原专家，名称、职责、工作方法和默认能力仍在，ID 不变。这个核对不要求恢复上次选择；选择仍是面板内存状态。修改前／修改后／冷重开加载 Client 与对应构建去除 sourceMappingURL 后精确匹配，Host 构建 SHA-256 与基线完全相同。原始摘要及检查项见 [native-proof.json](native-proof.json)。真实窗口标题计算字号 22px，无横向溢出。
