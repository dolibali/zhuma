# v1.5.1 范围、安装与来源

v1.5.1 是铸码的补丁版本，收录工作流可读性、成员姓名及工作入口优化。功能基线为 develop `699be8c94876baa87709c3112887a1d52f684dae`，发行准备、最终 main 来源、平台资格与公开资产由[工作项 #449](https://github.com/dolibali/zhuma/issues/449)记录。正式下载以 [Releases](https://github.com/dolibali/zhuma/releases) 为准；版本号和本说明本身不表示安装包已发布。

## 本版改进

| 范围                | 使用上的变化                                                                                                                                                                      | 已合入改动                                         |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| 工作流连线与全图    | 连线避让节点，概览包含节点和连线范围；缩放及缩略图放在独立底栏，主动拖动、缩放或定位后保持当前视口。                                                                              | [#439](https://github.com/dolibali/zhuma/pull/439) |
| 普通参与者打开任务  | 本机非任务负责人只读打开任务时，不再读取仅负责人可用的工作流控制区而产生误导错误；个人节点处理入口与原授权保留。                                                                  | [#441](https://github.com/dolibali/zhuma/pull/441) |
| 执行顺序与依赖      | 画布及模板预览默认突出执行顺序，可切换“全部依赖”核对完整前置关系；分支、汇合、手工连线和实际执行数据保持。                                                                        | [#442](https://github.com/dolibali/zhuma/pull/442) |
| 成员姓名与资产状态  | 在“账号与团队 → 个人资料”维护显示姓名，任务、分工、工作流、评审及发布者显示当前有权目录中的姓名；未知历史成员回退原账号。资产同时显示已发布版本与保留草稿，项目补充固定资料计数。 | [#444](https://github.com/dolibali/zhuma/pull/444) |
| AI 计划及工作树布局 | 按真实卡片尺寸处理密集初始坐标，避免重叠与连线遮挡；AI 草案替换节点时保持概览。工作树紧凑显示各层工作流，保留当前位置、层级和完整依赖；待办负责人同步当前姓名。                   | [#446](https://github.com/dolibali/zhuma/pull/446) |
| 导出与运行配置      | “我的工作”标题右侧统一“导出”菜单，保留 JSON/CSV 下载。模型、执行者和执行范围对齐，设置入口移到“更多 → CLI 设置”，选择器及摘要显示“码道 CLI”，菜单与设置关闭后正常返回焦点。       | [#448](https://github.com/dolibali/zhuma/pull/448) |

初始布局只修正明显碰撞或不足的端口间距，正常手工坐标保留；“整理布局”在可编辑草稿中可明确保存，预览和已确认计划仅改变当前视图。姓名用于展示，不替代稳定成员身份、授权或固定计划历史。码道 CLI 的名称与入口调整不改变实际模型值、配置命令、执行适配或权限。

根 README 同步整理为产品定位、功能、下载与上手入口。工程结构和实现来源继续保留在开发与架构文档，许可证、第三方版权及来源声明保持完整。

## 下载与安装

从本版正式 Release 下载对应平台产物、`SOURCE.json` 和 `SHA256SUMS`，核对文件名、版本及摘要。Windows 公开安装包继续使用 `windows-x64` 命名。

| 平台                 | 本版文件                                         | 安装与限制                                                    |
| -------------------- | ------------------------------------------------ | ------------------------------------------------------------- |
| Windows x64          | `zhuma-1.5.1-windows-x64-unsigned.exe`           | 原 NSIS 安装器，未提供 Authenticode 签名或自动更新。          |
| macOS Apple Silicon  | `zhuma-1.5.1-mac-arm64-unsigned.dmg`             | 将 Zhuma 拖入 Applications；ad-hoc 签名，未公证，无自动更新。 |
| Linux amd64 服务镜像 | `zhuma-1.5.1-server-linux-amd64-image.tar.gz`    | Docker SAVE 压缩字节，使用 `docker load -i <文件>`。          |
| Linux amd64 便携服务 | `zhuma-1.5.1-server-linux-amd64-portable.tar.gz` | 需要 Node.js 24.15.0 和对应原生库，按包内说明启动。           |
| 部署材料             | `zhuma-1.5.1-deployment.tar.gz`                  | 同一源码的服务说明、Dockerfile 与单实例 K8s 模板。            |

Windows 和服务原始来源清单分别保留为 `windows-SOURCE.json`、`server-SOURCE.json`。总清单绑定准确源码、tree、固定运行依赖及各平台原资产摘要。Intel Mac、Windows arm64 和 Linux 桌面仍不在支持范围；签名与平台范围不因补丁改号扩大。

## 升级与已有数据

客户端安装不会自动升级已部署的共享服务。按操作者安排使用匹配的客户端和服务版本；服务沿原部署、权限与入口进行最小升级，先备份再保留原持久卷、成员、项目、任务和固定产物。不用其他安装的个人配置目录覆盖原目录，用户凭据、会话和私有文件不进入公开发行包。

已有项目、任务、工作流、模型与工作区配置继续沿原入口使用。显示姓名是原身份数据上的增量资料；旧数据没有姓名时保留账号展示。安装或重新打开应用不会自动开始任务；模型执行与文件访问仍需原明确操作和授权。升级与必要冷启动结果以本版准确候选的实际记录为准。
