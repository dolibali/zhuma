# A-UX1 界面验证

日期：2026-10-22。范围为任务清单、工作流编辑/查看、AI 草案审阅和共享控件。使用固定版本的官方 DSH Web Host、隔离测试数据与 Chromium；不是 Electron 安装包验证，也不是产品视觉验收结论。

## 真实业务路径

在浏览器创建“订单导出与筛选改进”任务，选择两位真实成员定义及界面、质量专家，实际调用用户授权的 DeepSeek 模型。返回六节点、零关键问题，前后端并行，引用了导入的评审 Skill。预览 → 应用 → 把首节点执行者改为陈宁、评审人改为质量专家 → 保存 → 重开 → 工作树定位。此处成员是本地目录定义，不代表远程登录。

主题切换期间保留未保存节点名称、选中节点和画布 transform，观测到零次工作台 command/plan 请求。快速切换后等待官方设置写入，再刷新恢复最终偏好；system 模式随模拟操作系统浅深偏好变化。官方主题系统负责状态与持久化。

## 界面状态与尺寸

- 相同十节点并行工作流、长中文目标、22 位参与者，覆盖 1440×900、1280×800、1920×1080 浅/深主题。小地图有十个节点，默认 100% 画布，主动“适应全图”用于概览。
- 1024px 使用可关闭抽屉，Shift+Tab 保持焦点在抽屉内，Escape 关闭。人员搜索与多选共用控件；评审目录排除执行者，21 个候选、3 位已选。
- 查看态没有伪装成可编辑的输入框。草稿支持修改人员、评审、节点文字和依赖；长内容按需展开。
- 720×450 的缩小布局暴露了画布 min-height 导致底部控制区超出的问题，已去掉固定最小高度。Playwright 的 Meta+Equal 未改变浏览器原生缩放，所以这是缩小视口的重排检查，**不能称为原生 200% 缩放通过**；原生浏览器/安装版仍需补验。
- 搜索无结果有清除筛选动作。通过浏览器请求拦截制造读取延迟与错误，验证加载、错误、重试后恢复到真实 Host。这部分是故障注入的 UI 契约检查，不是服务故障恢复能力证明。

## 按钮核对

主、次、轻量、危险共用一组定义，正常、hover、pressed、键盘 focus 都通过真实 DOM 操作留图。已有草案时侧栏只有一个 primary。加载宽度不变、aria-busy=true；禁用态 computed appearance=none、opacity=1，浅色背景 rgb(240,241,243)，深色背景 rgb(37,41,47)，不再以整块透明度造成亮块。

按钮视觉对照复用了上一次真实模型返回的六节点响应，通过浏览器拦截重放，未额外调用模型；不将该重放计入真实模型成功次数。此前真实生成和保存链路独立保留证据。
