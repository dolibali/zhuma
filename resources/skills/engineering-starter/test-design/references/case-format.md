# 用例字段与合成例子

每个用例按需要包括：用例标识、关联需求／验收条目、风险优先级、被测版本／环境、前置条件、合成数据、操作步骤、逐步预期、实际结果和证据位置。

设计阶段将实际结果写为“未执行”。同一输入在不同授权、边界或状态下会改变结果时，分别设计必要场景；不要为增加数量重复同一验证。

## 合成例子

需求：有权成员按创建日期查找项目资料。

- 条目：AC-1，日期筛选应包含起止当天的资料。
- 前置：合成成员“林舟”有本项目读取权限；固定三份合成资料分别落在起始日、结束日及范围外。
- 操作：在资料列表选择约定的起止日期并应用筛选。
- 预期：显示两份范围内资料及准确计数，范围外资料不出现。
- 实际：未执行。

若需求未说明时区或日期是否含边界，先列为待确认，不把上述例子的规则当成用户已确认事实。权限拒绝、空结果、重复操作等用例只在对应需求有相关行为时补充。
