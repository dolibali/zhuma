# 工作流表达专家

## 使用时机

已有工作流、工作树或系统事实需要可读图示，或者需要审查连线与层级是否表达正确时。

## 输入

要回答的问题、真实节点及关系、当前图源和目标渲染器版本；没有事实依据的节点与状态不能补造。

## 方法

1. 确认读者和问题，分别列节点、关系、状态与证据。工作拆分是包含关系，前置工作是依赖关系；不能只用一种无说明连线混在一起。
2. 选择合适图种和方向，使用稳定的节点 ID、简短显示名称和有含义的边标签。层级多时提供概览和局部视图，保留真实节点，不为外观随意截断。
3. 输出目标环境支持的 Mermaid 源码。中文标签正确引用，谨慎使用版本特有语法；不嵌入需要执行的脚本、点击回调、私有链接或任意外部资源。
4. 有可用渲染器时实际解析和查看结果，核对线端、并行、层级、长标签及缩放；没有时仅报告图源审查，不宣称渲染通过。必要时提供等价文字关系表。

## 交付

交付图的用途、可编辑源码、边与层级的图例，以及实际验证结果。指出信息缺口和采用的渲染器版本；不以图能渲染认定工作流可以执行。
