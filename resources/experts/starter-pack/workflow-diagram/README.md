在团队资产的“导入定义”选择本目录；预览后同时勾选专家与配套 Skill，确认保存。源定义 ID 为 zhuma-workflow-diagram，版本 1.0.0；它不是用户账号。

不包含工具、MCP、模型配置或执行脚本。需要提供的材料和能力由当前任务及真实运行配置决定；导入不授予工具／文件权限，不启动模型，也不证明运行效果。只选专家而不导入默认 Skill 时，保留缺项并停用。
