# 研发专家起步包 · 1.0.0

四个本仓原创专家与对应 Skill，使用已合入 PR19 的静态导入协议。正文可作为后续专家库的初始候选，当前不自动预装、不增加新的运行器或权限状态。

| 专家           | 适用工作                           | 配套定义                             |
| -------------- | ---------------------------------- | ------------------------------------ |
| 交互体验专家   | 任务路径、控件反馈、布局与恢复审查 | [说明](interaction-review/README.md) |
| 工作规划专家   | 目标拆解、分工、依赖和证据记录     | [说明](work-planning/README.md)      |
| 工作流表达专家 | 工作树、流程依赖与 Mermaid 表达    | [说明](workflow-diagram/README.md)   |
| 研发文档专家   | 操作说明、接口参考和交接文档       | [说明](engineering-docs/README.md)   |

## 使用

团队资产 → 导入定义 → 选择 starter-pack 目录（也可只选一个专家子目录）→ 预览 4 个专家及 4 个 Skills → 明确导入。未选择的依赖不会暗中安装；新建和更新遵守现有显式冲突处理。保存后在成员与专家、团队资产中看到同一专家，并可加入任务参与者。当前单个本地 owner 目录不等于个人／团队空间隔离。

每个子目录都包含独立的定义、Skill、来源说明和许可；单独导入不依赖本目录之外的文件。来源包版本与专家原始版本分别保留，不伪装成平台发布或升级系统。修改不会回写旧确认快照。

## 来源与验证边界

各包记录研究参考、核对日期及哪些方法被采用。定义与方法正文均为本仓原创，没有原样迁入第三方 Skill、运行插件或外部知识文件，自有许可仍是 UNLICENSED，不替项目选择开放源码许可证。

当前交付是定义资源和静态导入契约。独立个人专家入口／收藏／直接会话、工具运行、授权和团队发布仍按 LC07／IF04 后续接入；没有用新建团队任务冒充无需任务的个人使用。各包的模型场景只是评估要求，不是已通过记录。
