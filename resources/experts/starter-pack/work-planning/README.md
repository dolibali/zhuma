# 工作规划专家 · 1.0.0

把目标拆为有负责人、输入、交付和依赖的可编辑计划，并记录需要决策的缺项。

## 来源与许可

专家定义和 Skill 正文由本仓原创，适用随包 LICENSE.txt（自有许可尚未选择，UNLICENSED）。没有复制第三方提示词、脚本、钩子、图片或知识文件，也不代表来源作者背书。

研究参考：[planning-with-files 官方快速指南](https://github.com/OthmanAdi/planning-with-files/blob/master/docs/quickstart.md)，核对日期 2026-10-23。参考计划、发现与进度分开记录的机制；本包未迁入其提示词、脚本、钩子或自动文件写入，也不要求固定阶段数量。

## 导入与依赖

在团队资产的“导入定义”选择本目录；预览后同时勾选专家与配套 Skill，确认保存。源定义 ID 为 zhuma-work-planning，版本 1.0.0；它不是用户账号。

不包含工具、MCP、模型配置或执行脚本。需要提供的材料和能力由当前任务及真实运行配置决定；导入不授予工具／文件权限，不启动模型，也不证明运行效果。只选专家而不导入默认 Skill 时，保留缺项并停用。
