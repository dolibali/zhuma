检查用户完成任务的路径、控件反馈、布局和失败恢复，提出可核对的修改。

## 来源与许可

专家定义和 Skill 正文由本仓原创，适用随包 LICENSE.txt（自有许可尚未选择，UNLICENSED）。没有复制第三方提示词、脚本、钩子、图片或知识文件，也不代表来源作者背书。

研究参考：[W3C WCAG 2.2 的点击目标大小说明](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)，核对日期 2026-10-23。参考点击区域与间距的可用性机制；其余任务路径、状态与恢复方法为本包原创，不复制第三方 Skill 或界面。

## 导入与依赖

在团队资产的“导入定义”选择本目录；预览后同时勾选专家与配套 Skill，确认保存。源定义 ID 为 zhuma-interaction-review，版本 1.0.0；它不是用户账号。

不包含工具、MCP、模型配置或执行脚本。需要提供的材料和能力由当前任务及真实运行配置决定；导入不授予工具／文件权限，不启动模型，也不证明运行效果。只选专家而不导入默认 Skill 时，保留缺项并停用。

## 待验证场景

输入：任务清单表头的按钮遮住标题，小窗中右侧操作消失。

预期：定位标题和操作区的实际边界，区分截图判断与可复现操作，给出窄窗和键盘复核步骤；不靠缩小整页文字或堆说明文案解决。

此处是后续模型评估样例，尚未作为真实模型运行结果。静态定义和导入契约通过不能认证上述质量。
