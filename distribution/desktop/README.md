# 桌面发行集成

官方 Electron 代码使用 `upstream/deepseek-harness/apps/desktop/`，不另复制桌面应用。

本目录负责后续将固定上游、自研 Bundle、品牌与必要补丁组成安装包。使用 `.build/` 临时树，保持上游检出干净。`branding/default/brand.json` 是本项目输入，尚未接到上游构建脚本；当前不能直接用于生成已改品牌安装包。

发布前必须验证：独立应用与数据标识、图标、签名、退出和后台任务、插件装载、重开历史、卸载、更新来源、干净机器启动。不得沿用官方产品的更新源、签名或账号身份冒充自有产品。

未配置签名和自有更新服务时，更新默认关闭，不猜测发行地址。不要让桌面构建自动安装 latest DSH。
