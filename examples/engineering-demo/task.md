# 任务：让运营订单导入容忍常见文件差异，拆出可复用校验

运营从现有系统导出的 CSV 可能带 UTF-8 BOM 和空行，重复导出还会带相同订单号。现在预览结果不可靠，损坏的 UTF-8 字节也会被替换成字符后继续处理。请实现下列可观察行为，同时把 CSV 记录解析与订单校验拆开，保持原接口和金额计算。

## 授权范围与保持行为

仅修改独立工程目录中的 `src/**`、`server.mjs`、必要的 `public/**` 和增量 `tests/**`。不可修改独立验收器、fixtures、原测试断言、项目命令或依赖来掩盖失败；不安装工具、不调用额外模型、不读产品凭据、不部署、不向真实系统写订单。不重做页面或引入框架。

保持：`importOrders(text)` 返回 `{ orders, errors, summary }`；订单字段为 `orderId/customer/quantity/unitPriceCents/totalCents`，错误为 `line/code/message`，summary 为 `rows/accepted/rejected/totalCents`。金额以安全整数“分”计算；正整数数量、两位以内非负单价、列数/必填/溢出错误继续生效。CSV 方言仍不支持引号和字段内换行。原 JSON API、原始 CSV API、64 KiB 限制、400/413/415/404 边界保持。
